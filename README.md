# Hola desde GitHub — módulo de ejemplo de Vitrina

Proyecto mínimo para probar **Panel › Módulos › Instalar desde GitHub** (Vitrina 0.8.1).

- `demo.json`: nombre, descripción y tipo del módulo (lo que Vitrina necesita para reconocerlo).
- `index.html`: la página.
- `api.py`: una función (`saludar`) que corre dentro de Vitrina.

El contrato completo está en `docs/contrato-de-modulo.md` de Vitrina.
